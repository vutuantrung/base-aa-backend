# R7.10.A — Breadth-First Architecture Scope & Responsibility Matrix

**Status:** discovery only; every new AS decision is pending owner approval. **Baseline:** `ea08e70f7855c96e8ce7ab18c83c224aada1f545` (`main`). **Scope:** observed local source, tracked tests and accepted decisions; no implementation or ownership reclassification.

## Evidence language and interpretation

- **Source observed** describes current tracked implementation. **Test evidence** describes local assertions/execution only. **Owner decision** is an accepted compatibility or policy constraint. **Hypothesis** is a risk without demonstrated operational consequence. **Unknown** means repository evidence does not answer it.
- “Business responsibility” below describes capabilities visible in source and contracts; it does not establish product ownership, deployment topology, or which external users depend on a capability.
- M01–M18 are implementation responsibility labels. Infrastructure adapters (M03/M05/M07/M08/M17) are distinguished from domain/protocol capabilities, not treated as business owners. M12/M13 remain TBD; M14/M15 remain APP.
- `docs/architecture/ARCHITECTURE.md` remains a historical system narrative. Current source and the current module map below take precedence where it differs.

## Accepted cross-cutting constraints and open questions

- R7.5 P01–P06 remain binding: receipt is local persistence, peer ACK is not business completion, uncertain send does not replay without receiver dedupe, bounded attempts/quotas/locks remain, and local process-kill evidence is not power-loss/deployment proof.
- R7.6 D01–D06 remain binding: admission cutoff, tracked work, one monotonic bounded deadline, startup rollback, late settlement and writer-lease retention. Timeout is not cancellation.
- R7.7 preserves the 55-file manifest, serial backend command, additive profiles, separate playground and explicit unknown mappings. This checkpoint does not relabel any row.
- R7.8 C-D01/02/03=A retains `src/app/lifecycle.ts` → `src/examples/pserver-to-aaui.ts`, callback-before-registration-before-listen and app-local transformation registry; top-level/nested gates remain distinct.
- R7.9 RC-D01–D07 and FI-D01–D05 remain accepted; M02 extraction is deferred because equivalence is not proven. F1 file reopen is not native-handle proof; F2 asynchronous close remains not proven; historical Full discrepancy remains unresolved, and earlier failures unattributed. TD15–TD17 and all other open debt remain as recorded.
- Product intent, M12/M13 ownership, external consumers, PServer deployment, operational log/readiness requirements, catalog data migration and target durability requirements need product/operator/external-client evidence. They cannot be inferred from module names, demos or tests.
