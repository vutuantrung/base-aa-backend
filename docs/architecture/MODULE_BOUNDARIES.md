## Import/ownership caveats
M02 is composition root; avoid service locator and new runtime cycles. M04 consumes M03 event capability; no raw socket in protocol contracts. M06 logical state is not a second socket map. M10 imports M11 execution; M11 imports M10 contract types (type-only distinction matters). M12/M13 import M10 schema/types, not gateway classes. Compatibility re-exports `peer-messaging/{task-file-store,resource-selection-store}.ts` point to domain owners; they are not additional stores. M14/M15 legacy adapter files re-export canonical neutral types. M07 depends on neutral M14–M16 contracts; M02 public handles still concrete. `shared/transport/connectable-client.ts` re-exports infrastructure implementations; evaluate direction at R7.1. M07/M05 use generic message contracts in shared; do not claim dependency enforcement yet. M17 owns SQLite lifetime, M02 coordinates app lifecycle; domain repositories own records, not separate DB handles. Cross-cutting auth distributed; no M19 needed. See debt registry for concrete risks and validation.
