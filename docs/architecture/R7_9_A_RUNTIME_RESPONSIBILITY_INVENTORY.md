## Dependency and lifetime summary

- Process lifetime: `main.ts` signal listeners and process exit policy.
- Application lifetime: M02 coordinator, HTTP/Socket.IO servers, optional PServer client, one SQLite handle, repositories and app-local registries.
- Peer-gateway lifetime: M06 directory, M10 service, M12/M13 workflows/stores/runners, listeners/snapshots; M02 fences, waits and closes through gateway capabilities.
- Durable state lifetime: M12/M13 configured JSON directories and M17 SQLite path; preserve persisted formats and locks.
- Playground lifetime: separate `testing/` process/package; wire peers are external to APP’s static module graph.
- Direction: entrypoint/config → M02 → gateways/adapters/modules and persistence. M09/M10/M11/M12/M13 aggregation SCC is a module ownership graph condition, not a file runtime SCC; no SCC cleanup is prescribed from this fact alone.
