# R7.10.B — Exact Feature-Mode Compatibility Matrix

**Status:** characterization evidence only; no runtime/contract change. **Committed source baseline:** `ea08e70f7855c96e8ce7ab18c83c224aada1f545` on `main`; R7.10.A docs remained uncommitted and preserved. New tests exercise only existing public inputs and loopback interfaces.

## Evidence labels

- **SOURCE-CONFIRMED:** direct behavior in the named current source symbol; not necessarily executed end-to-end.
- **TEST-OBSERVED:** named assertion or local test result observes the described behavior.
- **NOT TESTED:** source predicts a behavior but no specific assertion was run.
- **EXTERNAL DEPENDENCY:** outcome needs a real external peer/operator/deployment and is not established by local tests.

Tests establish local behavior only. `pserverConnector` existence means constructed; its `connected` state and protocol session readiness are separate. “Peer gateway exists” is distinct from it being started during `listen` or from any external peer being connected.

## Tested, inferred, external, and unobservable boundaries

- **Tested:** exact gate parsing representatives; factory SQLite omitted/true/false handles; PServer connector absent/present/disconnected on factory return; F2 invalid UDID error; direct-start top=true/nested=false registration order; direct-start top=false/nested=true no-rule plus local `/peers`; demo transform behavior from existing local mock; auth-first/SQLite-disabled HTTP responses.
- **Source-inferred:** CLI main signal installation and `onCreated` ownership; connection is invoked after peer start/listen/activate; workflow runner start timing; malformed PServer config ignored when the nested gateway is absent. These were not separately exercised as launched executable modes.
- **External/unverified:** production PServer availability/session semantics, real operator environment strings, deployment DB/store paths, production consumers of direct APIs, remote peer behavior, power loss and target filesystem semantics.
- **Not distinguished by current public API:** internal workflow object identity or runner state before/after activation; constructor existence is inferred from source. Tests deliberately use `/peers` and close/listen effects rather than introducing production seams.

No default, gate, module classification or behavior changed. M12/M13 remain TBD; M14/M15 remain APP. M02 extraction remains DEFERRED—EQUIVALENCE NOT PROVEN. R7.5–R7.9 ACK, durability, lifecycle, testing, health and compatibility invariants remain in force.
